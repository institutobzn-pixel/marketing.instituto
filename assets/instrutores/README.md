# Fotos dos instrutores — Curso Como Vender para o Governo e Sistema S

Coloque aqui as duas fotos dos palestrantes, com exatamente estes nomes de arquivo (a página já está referenciando esses caminhos):

- `rodrigo-gamallo.jpg` — foto do Rodrigo Gamallo
- `lisandro-viana.jpg` — foto do Lisandro Viana

Recomendações:
- Formato quadrado (1:1), mínimo 400×400px, boa iluminação e fundo neutro — a foto aparece dentro de um círculo na página.
- JPG ou PNG, até ~500KB cada (evita a página lenta).
- Se preferir outro nome/extensão, é só avisar para o caminho ser ajustado em `index.html` (seção `.instrutor-foto`).

Enquanto as fotos não estiverem aqui, a página exibe automaticamente um monograma (iniciais em dourado sobre azul) no lugar da foto — nada quebra visualmente.
