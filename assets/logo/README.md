# Logo — Instituto BZN

Coloque aqui os arquivos oficiais da logo (símbolo coração/mãos e wordmark), preferencialmente:

- `instituto-bzn-simbolo.svg` — símbolo isolado, vetorial (ideal)
- `instituto-bzn-simbolo.png` — símbolo isolado, PNG fundo transparente, alta resolução (alternativa se não houver SVG)
- `instituto-bzn-wordmark.svg` / `.png` — logotipo completo (símbolo + "instituto brasa zona norte"), mesmas variações

Esses arquivos serão usados como referência oficial para o Brand Book (marca d'água, aplicações, templates).
